# 0002. Where the service runs / Къде работи услугата

*Status / Статус:* Proposed

## Context / Контекст

We need the same environment for both of us. / Трябва ни еднаква среда и за двама ни.

## Options / Варианти

- GitHub Codespace: same for everyone. Minus: needs internet. / Еднакъв за всички. Минус: иска интернет.
- Own laptop: works offline. Minus: different setups. / Работи без интернет. Минус: различни настройки.

## Decision / Решение

GitHub Codespace.

## Consequences / Последствия

We both run the service the same way. / И двамата пускаме услугата по един и същ начин.
