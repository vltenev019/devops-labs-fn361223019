# Glossary / Речник

> Keep the table in alphabetical order. One term per row. / Пазете таблицата по азбучен ред. Един термин на ред.

| Term / Термин | Meaning / Значение |
|---|---|

| Artifact | The packaged result of a build, e.g. a Docker image, ready to be deployed. / Пакетираният резултат от изграждането, напр. Docker образ, готов за внедряване. |
| Branch | A separate line of development. / Отделна линия на разработка. |
| CI | Continuous integration: every change is built and tested automatically. / Всяка промяна се изгражда и тества автоматично. |
| Commit | A recorded snapshot of changes. / Записано състояние на промените. |
| Container | An application running in isolation together with everything it needs, e.g. with Docker. / Приложение, което работи изолирано заедно с всичко нужно, напр. с Docker. |
| Deployment | Putting a version of the service where users can reach it. / Поставяне на версия на услугата там, където потребителите я достигат. |
| Health check | An endpoint that says whether the service is alive. / Адрес, който казва дали услугата е жива. |
| Issue | A task, bug or idea tracked on GitHub. / Задача, бъг или идея, проследявани в GitHub. |
| Merge | Combining changes from one branch into another. / Обединяване на промени от един клон в друг. |
| Pipeline | An automated sequence of steps a change goes through: build, test, deploy. / Автоматична поредица от стъпки, през които минава промяната: изграждане, тестове, внедряване. |
| Pull request | A proposal to merge one branch into another, with review. / Предложение един клон да се слее в друг, с ревю. |
| Release | A published version of the software. / Публикувана версия на софтуера. |
| Rollback | Reducing, reversing, or undoing a change to return something to a previous state, lower level, or earlier version. / Намаляване, обръщане или отмяна на промяна, 
за да се върне нещо в предишно състояние, на по-ниско ниво или към по-ранна версия. |
| Runner | An application that runs jobs in a CI/CD pipeline. / Приложение, което изпълнява задачи в CI/CD пайплайн. |
| Tag | A name attached to a specific commit, e.g. v0.2.0. / Име, закачено за конкретен commit, напр. v0.2.0. |
| Version | A named state of the service, e.g. 0.2.0. / Именувано състояние на услугата, напр. 0.2.0. |
